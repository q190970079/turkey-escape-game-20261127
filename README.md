Turkey's Great Escape is a complete turkey escape game: a turkey outruns the farmer through the farmyard, the barn and the kitchen, dodging fences, falling carving knives and the oven's flames, grabbing corn, and reaching the forest gate to freedom.

## Run it

```sh
node serve.ts
```

Then open http://localhost:8080 in desktop Chrome and play with keyboard (SPACE jump, double jump, DOWN slide, SHIFT dash) or mouse (click to jump, click the buttons).
